【这是什么】
本压缩包是「个人博客项目」的配套教程文档站（绿色版），
内容只与你的 Python 博客项目相关，不含其它通用教程。

【包含内容】（共 16 份文档，左侧 tab 切换）
  01 零基础全流程开发教程   —— 从小白到跑通项目的手把手教程
  02 第三方库技术栈总目录   —— 项目用到的 12 个库总览
  03 全代码逐行注释文档     —— 路由/数据库/页面渲染/工具函数逐行讲解
  04 二次开发进阶文档       —— 可落地的功能扩展指南
  05~16 十二个技术栈库教程  —— Flask / Jinja2 / Werkzeug / Flask-SQLAlchemy /
       SQLite / python-markdown / Pygments / PyYAML / python-dateutil /
       waitress / pywebview / PyInstaller（均与博客项目实际用法绑定）

【怎么用】
  1. 解压到任意文件夹（建议英文路径，如 D:\blog-docs）
  2. 双击 index.html，用浏览器打开即可离线浏览
  3. 左侧 tab 切换文档；上方搜索框可搜索当前文档目录
  4. 右上角按钮可切换「日间 / 夜间」模式（会记住你的选择）

【技术说明】
  - 单文件离线网站，无需联网、无需安装任何软件
  - 所有内容已对照博客项目 v2.8.3 源码逐一核验
  - 兼容 Chrome / Edge / Firefox 等主流浏览器

【配套】

  与本包配套使用，可向豆包索取。
