【这是什么】
本压缩包是一个「纯 Python 第三方库教程网站」（绿色版），
只讲库本身，不与任何具体项目绑定。每一份都是
「从小白到大神」全套教程：是什么 → 核心概念 → 安装 →
API 全面讲解 → 实战项目案例（入门/进阶/综合三级）→
进阶内容 → 高频坑 → 学习路径与自测题。

【包含内容】（共 24 份教程 + 教程生成器 + 站点说明）
  浏览器自动化：Playwright（含与 Requests / BeautifulSoup4 /
                Pandas / Pillow / Openpyxl / Pytest 七库联动案例）、
                Selenium、PyAutoGUI
  网络与解析：  Requests、BeautifulSoup4
  数据分析：    Pandas、NumPy、Matplotlib、Openpyxl
  测试与图像：  Pytest、Pillow
  Web 框架：    Django、Flask、Jinja2、Werkzeug、Flask-SQLAlchemy
  数据存储：    SQLite
  内容文档：    python-markdown、Pygments、PyYAML
  时间处理：    python-dateutil
  部署桌面：    waitress、pywebview、PyInstaller

【教程生成器】
  点「🎓 教程生成器」页，输入库名（支持别名，如 bs4 / drf）：
  - 已收录 → 一键跳转到完整教程
  - 未收录 → 按提示把库名发给豆包，加入后下次即可生成

【怎么用】
  1. 解压到任意文件夹（建议英文路径）
  2. 双击 index.html，用浏览器打开即可离线浏览
  3. 左侧 tab 切换教程；右上角切换「日间 / 夜间」模式

【配套】
  另有一个「博客教程站」（博客专版）项目，与本包配套使用。
