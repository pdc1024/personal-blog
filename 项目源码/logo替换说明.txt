===========================================
 个人博客 · 图标（logo.ico）替换说明
===========================================

桌面上的「图标」其实分成 4 条独立链路，生效时机不同。
本程序已经全部配置好「用户可替换」，你只需要按下面说明改对应文件即可。


一、最快见效 · 窗口标题栏 / 任务栏 / ALT+TAB 图标
===================================================
【改哪个文件】
  软件安装目录里（一般是：
    C:\Users\你的用户名\AppData\Local\Programs\个人博客\logo.ico
  或
    右键桌面快捷方式 → 打开文件所在位置 → 看到 个人博客.exe 旁边的 logo.ico）
  → 直接把你自己的 ico 文件改名叫「logo.ico」把它覆盖掉。

【生效方式】
  关掉软件 → 重新打开软件 → 标题栏左上角、任务栏、按 ALT+TAB 切换窗口时，
  全部立即显示你替换的新图标（不需要重启电脑/重建缓存）。

【为什么能这么方便】
  程序启动时不会用 PyInstaller 内嵌的 exe 图标去做窗口，
  而是通过 Win32 API（LoadImageW + WM_SETICON）直接从磁盘读取
  「exe 同级的 logo.ico」文件，所以你覆盖哪个文件，下次启动就读哪个。

【ico 文件要求】
  建议是「多档 32-bit RGBA 带透明」的标准 Windows ICO，至少包含：
    16×16 / 24×24 / 32×32 / 48×48 / 64×64 / 128×128 / 256×256
 （否则会出现某一档尺寸被 Windows 放大后糊掉、或任务栏显示切角锯齿的情况。）


二、EXE 文件本身在资源管理器里的缩略图标（.exe 本体图标）
==========================================================
【改哪个文件】
  项目打包前的 logo.ico（源项目根目录）：
    C:\Users\Administrator\AppData\Roaming\...\6a93d81b...\logo.ico
  → 覆盖掉之后，重新跑 PyInstaller + Inno Setup：
      pyinstaller --noconfirm blog_desktop.spec
      "D:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss

【生效方式】
  重新生成的 onedir\个人博客.exe 以及
  installer_output\个人博客_安装包_v1.1.x.exe 里的 EXE 都会用新的
  logo.ico 作为「内嵌图标资源」（嵌入 PE 文件的 .rsrc\ICON 段）。

【注意】
  这个「.exe 本体图标」是 Windows 在你双击 EXE 之前、资源管理器看缩略时用到的，
  ≠ 软件真正跑起来的窗口/任务栏图标（那部分由上面「一」控制）。
  用户日常想换标，改「一」就够了；改本条只有重新打包的发布者才需要。


三、安装包向导 / 安装包自身 / 卸载项的图标
===========================================
【改哪个文件】
  项目根目录：
    logo.ico        —— SetupIconFile（安装包 exe 自身的缩略图标 / 控制面板卸载项图标）
    logo.png        —— 品牌占位（installer.iss 内部常量 MyAppLogo 引用，默认不显示）
    wizard_image.bmp        —— 安装向导左侧大图（164×314 BMP，24bit）
    wizard_smallimage.bmp   —— 安装向导右上角小图（55×58 BMP，24bit）
  → 覆盖后重新跑 ISCC。
     "D:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss


四、桌面 / 开始菜单快捷方式图标
===============================
【改哪个文件】
  其实快捷方式默认「继承 EXE 本体图标」，所以只要「二」改过了，重装软件或重建
  快捷方式就会刷新。如果你想让快捷方式图标也用「可热替换」的外置文件，我们的
  安装包已经把 UninstallDisplayIcon 和桌面快捷方式 IconLocation 都配好了。
  安装包生成的快捷方式位置：
    %USERPROFILE%\Desktop\个人博客.lnk
    %APPDATA%\Microsoft\Windows\Start Menu\Programs\个人博客\个人博客.lnk
  → 要换就先删了旧 .lnk，再运行安装包的「修复」或重新安装；
     或直接在属性 → 快捷方式 → 更改图标 → 选中 {app}\logo.ico。


五、优先级总览（按 main.py 加载顺序）
======================================
  窗口运行时加载的 ico 路径按以下顺序命中：
  1) exe 同级（DATA_DIR）的 logo.ico               ← 用户想换就改它 ✅
  2) _internal\logo.ico（PyInstaller 内嵌兜底）     ← 打包默认兜底
  3) 源项目根目录 logo.ico                           ← 开发模式兜底
  只有前面的路径不存在时才会 fall through 到后面。


六、常见疑问
============
Q: 我把 exe 旁边 logo.ico 换成新的了，为什么 EXE 缩略图没变？
A: 那是「二」的 PE 内嵌图标，它跟窗口图标是两套完全独立的链路；
   窗口图标（运行中标题栏/任务栏）已经是新的，就说明替换成功。

Q: 为什么推荐 256×256 档？
A: Win10/11 任务栏大图标、150%~250% 高 DPI 缩放下 Windows 会优先选 128/256
   档，缺的话会用 32 档放大，边缘会糊。

Q: 替换后任务栏还是旧图标？
A: 1) 确认你关掉了本程序（所有 个人博客.exe 进程都退出了，包括
      msedgewebview2 子进程）；
   2) 再重新打开；
   3) 还是不对的话，把 %LOCALAPPDATA%\IconCache.db 删掉后注销登录一次
      （Windows 资源管理器图标缓存，极少数情况下会残留旧档）。
