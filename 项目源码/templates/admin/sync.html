🧭 工作原理（永不覆盖更新的数据）

  • 📥 立即恢复（pull）：扫描 Gitee 的 jsonl 数据，每条记录用 updated_at 和本地比， 远端更新才写入；本地更新字段一律保留（字段级填空）。
  • 💾 立即备份（push）：只把本地 updated_at > 上次游标 的记录增量推送到 Gitee。 相同二进制附件自动免传（SHA 比对）。
  • 🔄 立即同步（both）：先 pull 再 push，两端都合并，相当于 Chrome 同步。
  • 🧱 同步范围：文章 / 标签 / 文章-标签 / 评论 / 点赞 / 友链 / 个人资料 / 站点设置 / 头像·背景图·文章图（二进制附件）。
💡 换新电脑： 安装 → 打开云同步 → 走上方「🚀 新手向导」填同一个 Gitee 令牌 → 点「📥 立即恢复」→ 数据自动合并到本机。已在新机器写的文章绝不会被覆盖。
