📝 Markdown (.md) 格式

推荐在顶部加 YAML front-matter 指定元信息：

---
title: 我的文章标题
summary: 这是摘要，不写自动截取
category: 编程笔记
tags:
  - Python
  - Flask
  - Web
date: 2026-08-30
published: true
---

# 这里是正文 Markdown 内容

正常写就可以啦……

💡 没写 title 时会自动从正文第一个 # 标题或文件名取

📋 YAML (.yaml/.yml) 格式

单篇或多篇数组，适合批量导入：

# 单篇（对象）
title: 文章标题
category: 生活
tags: [日记, 日常]
content: |
  # 标题
  这里是正文内容……

---

# 或批量多篇（数组）
- title: 文章一
  category: 编程
  tags: [Python]
  content: "**正文**"

- title: 文章二
  category: 笔记
  published: false
  content: 内容……

💡 常用字段：title / content 必填，tags 支持数组或逗号字符串
